# 📝 One Line Journal

A minimalist daily journaling app where users write just one line per day to reflect or capture their mood. Built for simplicity and emotional awareness.

## 🎯 Core Features

- **One-line journaling**: Encourage short, consistent reflections
- **Mood tracker**: Choose from emojis (🙂 😐 😔) or custom emojis
- **Word counter**: Live count to stay within the one-line spirit (200 character limit)
- **Streak tracker**: Track your writing streak (🔥 Days in a row)
- **Local storage**: All data is stored in the browser, no sign-in needed
- **Beautiful UI**: Modern, responsive design with smooth animations

## 🚀 Getting Started

1. **Download the files**: Save `index.html`, `styles` directory, and `scripts` directory to a folder
2. **Open in browser**: Double-click `index.html` or open it in your preferred web browser
3. **Complete onboarding**: Follow the interactive tutorial to learn the features
4. **Start journaling**: Write your first one-line reflection and select your mood!

## ✨ How to Use

### Writing Your Entry
1. Type your reflection in the text area (max 200 characters)
2. **Voice Input**: Click the 🎤 button for hands-free voice-to-text input
3. Select your mood using the emoji buttons or custom mood picker
4. Add optional tags to organize your thoughts
5. Click "Save Today's Entry"

### V3.0 Advanced Features

#### 🗣️ Voice-to-Text Input
- **Enable**: Go to Settings (⚙️) and toggle "Voice Input"
- **Use**: Click the 🎤 button next to the text area
- **Speak**: Your words will be transcribed automatically
- **Edit**: Voice text is inserted into the text area for manual editing

#### 🤖 AI Journal Summary
- **Setup**: Go to Settings → "AI Journal Summary" → "Configure AI"
- **Providers**: Choose from OpenAI, Groq, xAI, or Anthropic
- **API Key**: Enter your API key (stored locally and securely)
- **Generate**: Click "Generate Summary" for weekly insights
- **Test**: Use "Test Connection" to verify your setup

#### 🧘 Daily Wisdom Quotes
- **Enable**: Go to Settings and toggle "Daily Wisdom Quotes"
- **Customize**: Click "Customize Quotes" to add your own
- **Refresh**: Click the 🔄 button for a new quote
- **Default**: 10 inspirational quotes included

#### ⚙️ Settings Management
- **Access**: Click the ⚙️ button in the header
- **Voice Input**: Enable/disable speech recognition
- **Wisdom Quotes**: Toggle daily motivational quotes
- **AI Features**: Enable/disable AI summary capabilities

### V2.0 Advanced Features
- **Custom Moods**: Click the 🎨 button to choose from 12 additional emojis
- **Tags**: Add tags like #gratitude #goal #work to categorize entries
- **Edit Entries**: Click the ✏️ button on any entry to modify it
- **Delete Entries**: Click the 🗑️ button to remove entries
- **Search**: Use the search bar to find specific entries
- **Filter**: Filter by mood or tags using the dropdown menus

### Calendar View
- **Visual Overview**: See your journaling pattern at a glance
- **Mood Dots**: Each day with an entry shows your mood emoji
- **Click to Edit**: Click any day with an entry to edit it
- **Navigate Months**: Use the arrow buttons to browse different months

### Backup & Restore
- **Export**: Click the 💾 button and select "Export Journal" to download your data
- **Import**: Use "Import Journal" to restore from a backup file
- **Automatic**: Your data is automatically saved locally

### Dark Mode
- **Toggle**: Click the 🌙/☀️ button in the header to switch themes
- **Persistent**: Your theme preference is saved automatically

## 📊 Enhanced Stats

- **🔥 Day Streak**: Consecutive days of journaling
- **Total Entries**: Your total number of entries
- **Today's Mood**: Your current mood selection
- **Average Mood**: Overall mood trend across all entries

## 📊 Data Structure

Each journal entry contains:
```javascript
{
  date: "2024-01-15",
  text: "Your one-line reflection",
  mood: "happy|neutral|sad|custom",
  customMoodEmoji: "😊", // Only for custom moods
  tags: ["gratitude", "goal"],
  timestamp: "2024-01-15T10:30:00.000Z"
}
```

## 🔧 Customization

You can easily customize the app by modifying:
- **Colors**: Update CSS custom properties in `styles/theme.css`
- **Mood Options**: Add more mood emojis in both HTML and JavaScript
- **Character Limit**: Change the 200 character limit in HTML and JavaScript
- **Storage Keys**: Modify the localStorage keys in `scripts/config.js`
- **Reminder Time**: Change the default reminder time (currently 8 PM)
